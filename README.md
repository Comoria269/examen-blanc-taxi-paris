# Examen blanc — Taxi parisien

Application web de révision pour les candidats à l’examen de conducteur de taxi parisien.

## Fonctionnalités

- Banque de 60 questions.
- Examen de 24 questions tirées aléatoirement.
- Mélange des questions et des propositions de réponse.
- QCM, vrai/faux, association, réponses courtes, calculs, mises en situation et logique.
- Correction automatique avec score sur 24 et explications.
- Bilan par thème : réglementation, territoire et calcul.
- Identification des questions à revoir.

## Utilisation

1. Télécharger ou cloner ce dépôt.
2. Ouvrir `index.html` dans un navigateur.
3. Répondre aux questions de l’examen généré au chargement.
4. Cliquer sur « Corriger mon examen » pour consulter les résultats.
5. Cliquer sur « Générer un nouvel examen » pour une nouvelle session.

Aucune installation, dépendance externe ou base de données n’est nécessaire.

## Technologies

HTML, CSS et JavaScript natif, réunis dans `index.html`.

## Structure

- `index.html` : interface, banque de questions et logique du quiz.
- `README.md` : présentation et utilisation du projet.

## Limites et avertissement

Outil personnel de révision, non officiel. Le format et le score ne constituent pas une validation de l’examen officiel. Les réponses réglementaires doivent être vérifiées auprès des sources officielles en vigueur avant utilisation comme support de préparation. La correction des réponses courtes repose sur la présence d’un mot-clé et peut manquer de précision. Les résultats ne sont pas sauvegardés après rechargement.
